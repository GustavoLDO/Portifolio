Bem-vindo ao repositório do meu portfólio pessoal. Este projeto é a vitrine das minhas competências técnicas, unindo design de alto nível (UX/UI) com uma arquitetura de software robusta e escalável.

## 🚀 Sobre o Projeto

O objetivo deste portfólio é demonstrar minha evolução como desenvolvedor, desde os fundamentos do Front-end até a orquestração de sistemas Full Stack complexos. A interface foi projetada com uma estética **Dark Mode**, utilizando gradientes em **Ciano e Roxo**, inspirada na identidade visual de tecnologias modernas e cultura geek.

### 🛠️ Tecnologias Utilizadas

- **Front-end:** React.js, TypeScript, Tailwind CSS.
- **Back-end:** Java (Spring Boot), Kotlin, Python (Django).
- **Banco de Dados:** PostgreSQL, MySQL.
- **Ferramentas:** Biome (Linting), Framer Motion (Animações), Git.

## 💎 Pilares de Desenvolvimento

- **Clean Code:** Código legível, modular e de fácil manutenção.
- **Performance:** Otimização de renderização no React e consultas eficientes no banco.
- **Scalability:** Estrutura preparada para o crescimento da aplicação.
- **UX/UI de Alto Nível:** Interfaces intuitivas e visualmente impactantes.

## 🗺️ Minha Jornada (Timeline)

- **2024:** Fundamentos Web (HTML/CSS/JS).
- **2025:** Especialização em Back-end (Java/Spring Boot/APIs).
- **2026:** Domínio Full Stack (React/TypeScript/PostgreSQL).

## ⚙️ Como executar o projeto localmente

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/GustavoLDO/Portifolio.git](https://github.com/GustavoLDO/Portifolio.git)
   ```
2.Instale as dependências:
```bash
    npm install
    # ou
    yarn install
  ```
3.Inicie o servidor de desenvolvimento:
   ```bash
      npm run dev
  ```
