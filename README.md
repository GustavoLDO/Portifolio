### 🛠️ Funcionalidades Principais

* **Interface Moderna:** Estilização limpa e intuitiva com Tailwind CSS.
* **Performance Otimizada:** Build rápido e eficiente utilizando Vite.
* **Tipagem Forte:** Desenvolvimento seguro e escalável com TypeScript.
* **Responsividade:** Adaptado para qualquer tamanho de tela (Mobile, Tablet e Desktop).

---

### 📦 Como Rodar o Projeto

Para testar o projeto localmente, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/GustavoLDO/Portifolio.git
    ```

2.  **Acesse o diretório:**
    ```bash
    cd Portifolio
    ```

3.  **Instale as dependências:**
    ```bash
    npm install
    ```

4.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```

---

### 📂 Estrutura de Pastas 

* `src/components`: Componentes reutilizáveis da interface.
* `src/assets`: Imagens, ícones e arquivos estáticos.
* `src/styles`: Configurações globais do Tailwind.
